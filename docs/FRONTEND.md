# 前端结构

当前前端使用 Vue Router、TanStack Vue Query 与 Reka UI；侧边栏按工作区、记录、配置常显分组，手机使用导航抽屉。

操作成功、失败与取消反馈统一通过 `app/toast.ts` 和根级 `ToastHost` 显示，不在页面内容流插入提示条。Toast 固定悬浮、自动消失，可关闭，悬停或聚焦暂停计时，同文案去重且最多显示三条；原生弹窗打开时挂载到最上层弹窗，退出登录时清空。字段校验、任务状态、查询失败重试页及整理预览冲突属于持续业务状态，保留在对应区域。

## 目录职责

- `frontend/src/app/`：路由表、登录守卫、查询客户端与缓存键、登录状态、跨页面运行状态及导航分组。
- `frontend/src/layouts/`：登录后的统一布局、侧边导航、页眉、移动端菜单与全局任务进度。
- `frontend/src/pages/`：各路由独立页面。`recognition/` 下分别放规则、历史、调试页面。
- `frontend/src/features/`：统一工作区、单集对照、设置表单与识别规则等业务状态和交互。
- `frontend/src/components/ui/`：通用页头、请求状态、通知和分页；`navigation/` 与 `jobs/` 分别提供导航和任务组件。
- 规则脚本使用按需加载的 CodeMirror 6，支持 JavaScript 高亮、补全、语法和运行错误定位；只解析草稿，不在浏览器执行。补全与 `scriptReference.ts` 使用当前阶段接口：来源、片段、候选、目录树和目标文件；不提供浏览器能力。历史源码只读。
- 普通标注与片名标注各自在组内移动、按 order 排序，片名始终最后。新增和修改身份会进入对应组；前后端顺序一致。
- 脚本编辑器下方按需展开阶段接口，说明分词、标注与建议的输入、输出、位置与资源限制。没有来源清理脚本或字段直接写入接口。
- `frontend/src/api.ts`：统一请求、错误类型、取消信号及会话失效处理；`model.ts` 定义接口数据类型。
- `tests/frontend/app/`、`tests/backend/app/spa_test.go`：路由守卫、导航、缓存、取消与生产静态资源回退测试。

## 路由

| 地址 | 页面 | 导航组 |
| --- | --- | --- |
| `/records` | 整理记录 | 记录 |
| `/recognition` | 整理工作区 | 工作区 |
| `/recognition/rules` | 识别规则 | 配置 |
| `/recognition/history` | 识别历史列表 | 记录 |
| `/recognition/history/:traceId` | 识别历史详情 | 记录 |
| `/recognition/debug` | 识别调试 | 配置 |
| `/settings` | 设置 | 配置 |

根地址跳转工作台。页面采用懒加载；登录守卫为未登录请求保留安全的站内返回地址。历史筛选、分页和设置分区使用 URL 查询参数，浏览器后退会恢复对应状态。生产服务器只为不存在的前端页面路径回退到入口 HTML，未知 API 和缺失资源仍返回 404。

识别历史列表和详情使用独立组件与查询。列表通过 `page` 和 `path` 保留分页与完整文件或上下文目录路径精确筛选；进入详情后返回列表会恢复该上下文，工作区直达详情则返回默认列表。详情默认展示执行过程，可切换提取结果与原始 JSON，切换记录时重置视图和步骤筛选。清理复用全局确认弹窗，仅删除指定轨迹及步骤；运行中的轨迹不能清理，清理后修正越界页码。

规则列表和单条编辑页共用未保存保护：站内跳转、浏览器后退与切换规则使用全局确认弹窗，刷新或关闭标签使用浏览器原生离开提示。后台规则查询刷新不会覆盖已载入的草稿。单条编辑页切换规则会清理前一条的试跑与样例状态。

操作菜单统一使用 `components/ui/ActionMenu.vue` 和 `ActionMenuItem.vue`，涵盖规则新增、工作区目录和文件更多操作。点击外部、再次点击入口、选择项目或按 Esc 均可关闭，支持方向键和 Enter，Esc 后焦点回到入口；点击外侧控件可直接执行其操作。菜单项支持禁用和链接，弹窗内的菜单挂载到所属弹窗，页面停用时收起。不要用原生 `details` 实现悬浮操作菜单；正文折叠仍使用 `details`。

规则新增菜单共用展开状态，验证或保存期间禁用并收起。「恢复默认规则」直接显示为次要文字按钮，经确认后只替换当前草稿并清理样例结果，仍需另行保存才生效；取消不改动草稿。

保存规则前使用当前完整草稿链调用现有样例接口；样例失败或接口错误时不发送保存请求，并展示路径、规则、期望值和实际值。只有与当前规则链完全一致的成功验证结果可复用，修改后标记过期；无样例时仍执行服务端规则编译校验并明确提示未配置样例。验证和保存期间禁用重复提交，页面销毁后中止验证并忽略过期响应。脚本接口说明通过就地参考面板查看，快捷键和试跑说明保留 Tooltip；试跑按文件展示片段、候选和识别建议，详细过程按需展开。

## 状态与请求

`EliText` 支持 `ellipsis="start"`（前省略，保留末尾）与 `ellipsis="end"`（后省略，默认）。所有专用的文件／目录路径展示统一使用前省略，涵盖工作区、确认表格、预览目标、整理记录、识别历史、样例、解析边界与设置授权目录；路径选择器同步使用前省略。只有实际溢出才提供完整文本 Tooltip，并在文字或尺寸变化后重新测量。文本保留完整 DOM 内容与正常阅读顺序；路径编辑框和原始 JSON／脚本日志不做省略，以免影响编辑、复制与诊断。

TanStack Query 统一管理服务端查询、去重、缓存、轮询、请求取消及写入后的失效更新。可编辑表单从查询结果复制，避免直接修改共享缓存。GET 临时失败最多重试一次，认证与参数错误不自动重试，写请求不自动重试。

整理与目录刮削共用三步页面：添加文件 → 确认 → 预览。第一步先暂存来源，点击开始识别才提交；整理补充来源复用工作区，刮削仍限定一个 Target 目录，更换目录明确新建工作区。恢复正在扫描的任务显示第一步，其余恢复到确认步骤，不复用旧预览。

确认采用目录导航和按作品分组的文件表单。目录列表首项为“全部”，目录项数字表示该范围的文件总数。目录、待确认／已确认状态、文件搜索按交集筛选，切换条件或确认成功均不重置其他条件；单目录只包含直接父目录内的文件，“全部”包含所有目录。目录只定义操作范围，不定义作品归属。逐文件草稿保存作品、季号、集数和取值依据，未确认文件初始归入“待指定作品”，识别匹配仅用于推荐；已确认文件以保存的作品初始化。按媒体类型与 TMDB ID 分组，未指定组在前，其余按作品名排序，同作品跨目录在“全部”视图下合并。各组只展示当前筛选结果，组内保留现有文件排序，标题滚动吸顶，窄屏操作换行。

作品推荐与搜索放入各组的“选择作品／更换作品”侧栏。选择仅修改当前筛选下该组已勾选文件的草稿，文件立即移动到对应作品组，保留勾选和季集，仍需显式确认。统一季号、集数映射、集目对照及组底部的“确认 N 个文件”均限定在该组当前筛选下勾选的文件；组内全选覆盖所有分页。每组独立校验、独立确认，成功后更新 revision 并保留其他组及隐藏文件的草稿与取消勾选状态，失败保留编辑。页面底部只提供前往预览，执行勾选位于预览步骤。离开保护覆盖所有未提交作品及季集修改，包括筛选外文件。

“调整集数”与集目对照复用 `SidePanel` 抽屉，独立滚动、固定底部操作，不撑高表格；支持点击外部、Esc 和关闭按钮。建议、候选、原文数字位置与绝对偏移先生成映射预览，应用后才修改草稿；结构不匹配的行保留人工内容并标出问题，缺集不补号。TMDB 集目可切季查看和填入单行，仍由同一确认接口原子保存。季度与集目缓存按作品隔离，搜索推荐来自当前操作范围，切换范围与关闭草稿使迟到响应失效。更换作品后重新校验季集；唯一季号仅在明确选择作品时预填草稿，日常校验不自动修改行值。后台锁定文件立即退出可操作范围。TMDB 季集读取中不显示行内错误，只在本组确认按钮显示加载状态；读取失败与无效季集保留对应问题。重新识别与依据入口收进更多菜单，重新识别作用于当前筛选结果。

预览步骤按已确认作品展示执行选择，作品名、文件数量与“选择文件”折叠入口同行；整理和刮削选项合并到生成预览按钮左侧的页脚，窄屏自动换行。刮削输出布局就地展开修正。整理方式、重复策略、刮削选项、文件勾选、布局、revision 或文件执行锁变化均使旧预览失效，点击生成预览后展示实际路径与冲突。只有有效预览可加入队列；全跳过的整理批次仍允许登记。提交后通过 Toast 反馈，工作区保留未提交文件。默认复制、跳过重复；刮削默认 NFO＋图片、只补缺失。桌面显示两栏，窄屏将目录导航收起为选择面板；同屏不出现编辑和执行两套文件勾选。

文件列表按季集数值与路径自然排序，所有排序仅影响展示，不改写映射，也不按排序生成集号。确认文件表每个作品组独立分页，每页 40 项，选择跨页保留；整理输出每页 30 项，刮削产物每页 50 项。

全局 `/queue` Query 在 `active=true` 或 `recognizing=true` 时每 1200ms 轮询，两个通道及识别都空闲后停止；挂载、聚焦、重连及提交失效会重新发现任务，不保存本地活动任务 ID。队列 revision 变化刷新记录、批次、等待列表、工作区和片库；详情只在打开时请求完整 Run，排队或运行期间自行轮询，用途与 ID 组成唯一缓存键。全局提示同时展示整理与刮削进度、等待数量及资源等待原因。

工作区和记录操作不依赖全局 executing 禁用；工作区仅在本次请求／识别期间限制操作，逐文件依据 `execution.locked/completed` 限制作品、季集、分组及重复提交。未提交文件可继续导入、修正和预览下一批；保存只发送相对已载入基线有变化的文件。后台状态刷新不增加工作区 revision，打开的季集草稿在保存时按路径定位当前文件并复核锁定。整理完成的视频退出整理选择。设置表单在运行、排队或识别期间仍禁止保存。

记录页通过 `/queue/items` 展示对应通道的分页等待任务，并支持查看和取消；整理记录另展示分页批次、队列位置和批次取消，`/batches` 不再表示最近一批。

多作品整理预览默认使用 `duplicatePolicy=skip`，可切换 `overwrite` 并重新请求后端预览；刷新期间及策略与预览不一致时禁用确认，失败反馈使用 Toast。行 `action` 显示新增、跳过重复或无备份覆盖。跳过已有有效视频时仍登记刮削映射，整批全跳过也允许执行登记；磁盘源文件保留，已完成登记文件退出整理选择。整理只包含视频及同名字幕，NFO/图片由独立刮削工作区生成。刮削工作区按需加载每次 50 部作品、搜索并加载更多；进入作品后才检查视频可用状态，季度和单集默认折叠，整部/整季选择不受当前筛选影响。默认批量只选待办与失败；已完成项需显式重刮，单次上限 1000 个视频。预览替换作品详情而非堆叠在下方，返回选择保留当前勾选；先显示共享和逐版本产物计数，完整路径按需展开搜索；离开页面不保留未提交勾选。整理进行时，刮削列表与当前作品持续发现新登记的视频，但不自动改变用户已有勾选；待复制／发布或状态不明视频不进入可选列表。已排队、执行中和不可用视频不能选择；两通道都结束后停止片库轮询。刮削记录单独查询和撤销。覆盖没有备份，撤销不能还原旧内容；目录、符号链接及同批次目标互撞仍阻止执行。

退出登录会取消查询、清空查询缓存和临时交互状态，并使此前发出的响应失效。服务端工作区保留。已停用的手动工作区浏览器数据不再读写，也不会自动删除或迁移。

测试统一存放在根目录 `tests/`，执行 `make check`。

## 业务状态归属

- `features/workspace/useWorkspace.ts` 协调步骤、实际目录、来源、持久化选择与确认；`useConfirmation` 维护逐文件作品与季集草稿、候选快照、分组、revision 及显式确认，`useConfirmationGroup` 维护各作品的搜索、TMDB 校验与季集工具，请求和响应随独立 effect scope 清理。`SourceStep.vue`、`ConfirmationForm.vue`、`PreviewStep.vue` 分别呈现三个步骤，`ConfirmationWorkGroup.vue` 呈现各组标题、表格、分页与确认操作，`LayoutEditor.vue` 在刮削预览内编辑输出目录；预览请求仍由两个用途的预览 composable 管理。
- `features/scrape/useScrape.ts` 管理刮削查询及操作；作品分页由 `useInfiniteQuery` 持有，视图从缓存派生，不再维护另一份累加列表。选中文件和筛选输入属于本地交互状态。
- `features/records/queries.ts` 统一整理与刮削记录查询，页面不直接发送记录操作。取消、重试及撤销由 runtime 统一处理并使用 toast 反馈。
- 活动摘要统一来自 `keys.queue`；详情统一使用含用途的 Run ID 缓存键，活动卡片不另发详情请求。任务结束刷新记录、片库及工作区缓存；没有活动任务时不轮询记录或片库。

服务端查询数据保持只读，可编辑工作区、设置和规则从查询结果复制草稿。页面负责布局及 DOM 交互，不成为额外的请求或业务状态所有者。


整理与刮削记录共用搜索／状态筛选，条件和页码存入路由 query，切换条件回到第一页，分页保留条件；Query key 包含用途、页码及两个条件，不沿用上一组结果。详情支持只看异常项，正常运行中的中间状态不作为异常。

设置的 `maintenance` 分区承载历史与缓存清理，识别历史页提供入口。预览数量后通过现有确认框提交，选项变化立即清除旧预览，处理中锁定输入；成功／失败沿用 toast。成功清理后移除历史详情缓存并刷新列表，失败保留预览供重试。


重新识别由 `useReidentification` 管理对话框范围、跨页选择和打开时的 revision，入口为目录更多菜单和单个文件；默认勾选范围内可用条目，已提交项禁用。`useWorkspace` 负责请求与接受任务快照，提交成功清除整理预览。对话框使用 EliText 展示路径，取消不发送请求，失败保留选择供复核重试。

刮削内容和只补缺失选项由 `useScrape` 持有，切换选项立即废弃预览并取消未完成请求；响应须同时匹配作品、选择路径及选项。预览分别列出计划生成和跳过的文件，全部已存在时不允许提交空任务。已完成标签表示最近所选刮削任务的结果。


刮削页提供已登记作品与目录刮削两个入口；目录选择器仅浏览 Target。目录流程复用工作区的分组、作品搜索、季集修正和重新识别，查询键包含 purpose；输出目录可按物理目录与季修正。默认只补缺失，批量预览展示全部实际输出和跳过路径并分页，不提交前端生成的文件操作。设置／revision／选项变化使预览失效，迟到响应与卸载后的响应均丢弃。完成反馈及错误使用现有 toast。

工作区通过 candidates 读取 revision 对应轨迹，不重跑脚本；候选、季目和搜索请求支持取消及迟到响应隔离。确认提交期间阻止重复确认；原文结构不一致、季集不存在或文件被其他任务占用的行必须修正或排除，不能静默部分保存。普通勾选、推荐作品或唯一季度不会授予确认资格。
