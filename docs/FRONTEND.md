# 前端结构

当前前端使用 Vue Router、TanStack Vue Query 与 Reka UI；侧边栏按工作区、记录、配置常显分组，手机使用导航抽屉。

操作成功、失败与取消反馈统一通过 `app/toast.ts` 和根级 `ToastHost` 显示，不在页面内容流插入提示条。Toast 固定悬浮、自动消失，可关闭，悬停或聚焦暂停计时，同文案去重且最多显示三条；原生弹窗打开时挂载到最上层弹窗，退出登录时清空。字段校验、任务状态、查询失败重试页及整理预览冲突属于持续业务状态，保留在对应区域。

## 目录职责

- `frontend/src/app/`：路由表、登录守卫、查询客户端与缓存键、登录状态、跨页面运行状态及导航分组。
- `frontend/src/layouts/`：登录后的统一布局、侧边导航、页眉、移动端菜单与全局任务进度。
- `frontend/src/pages/`：各路由独立页面。`recognition/` 下分别放规则、历史、调试页面。
- `frontend/src/features/`：统一工作区、单集对照、设置表单与识别规则等业务状态和交互。
- `frontend/src/components/ui/`：通用页头、请求状态、通知和分页；`navigation/` 与 `jobs/` 分别提供导航和任务组件。
- 规则脚本使用按需加载的 CodeMirror 6，支持 JavaScript 高亮、缩进、撤销重做与查找；补全包括只读 `ctx`、元数据、本规则参数，以及服务端 `trace`、`print`、Go 正则辅助函数。Acorn 只解析草稿语法、入口函数和脚本字节限制，不在浏览器执行代码；CodeMirror Lint 展示语法及试跑错误，点击错误定位对应提取脚本或来源清理脚本。浏览器 API 不加入运行时补全，实际可执行性仍以服务端验证为准。历史脚本快照保持只读展示。
- 主脚本与来源清理脚本在编辑器下方的返回约定文字末尾提供唯一的「脚本参考」入口，与说明共用一行，窄屏自然换行；点击后就地展开内置函数、输入上下文、返回值与运行规则。函数详情含签名、适用字段和可复制的完整示例，复制不会修改草稿，剪贴板不可用时提示手动复制。返回值说明跟随当前目标字段更新，来源清理单独说明字符串返回约束。`scriptReference.ts` 是参考面板与自动补全共用的接口说明数据源。
- `frontend/src/api.ts`：统一请求、错误类型、取消信号及会话失效处理。
- `tests/frontend/app/`、`tests/backend/app/spa_test.go`：路由守卫、导航、缓存、取消与生产静态资源回退测试。

## 路由

| 地址 | 页面 | 导航组 |
| --- | --- | --- |
| `/records` | 整理记录 | 记录 |
| `/recognition` | 整理工作区 | 工作区 |
| `/recognition/rules` | 识别规则 | 配置 |
| `/recognition/history` | 识别历史列表 | 记录 |
| `/recognition/history/:traceId` | 识别历史详情 | 记录 |
| `/recognition/debug` | 识别调试 | 配置 |
| `/settings` | 设置 | 配置 |

根地址跳转工作台。页面采用懒加载；登录守卫为未登录请求保留安全的站内返回地址。历史筛选、分页和设置分区使用 URL 查询参数，浏览器后退会恢复对应状态。生产服务器只为不存在的前端页面路径回退到入口 HTML，未知 API 和缺失资源仍返回 404。

识别历史列表和详情使用独立组件与查询。列表通过 `page` 和 `path` 保留分页与完整路径精确筛选；进入详情后返回列表会恢复该上下文，工作区直达详情则返回默认列表。详情默认展示执行过程，可切换提取结果与原始 JSON，切换记录时重置视图和步骤筛选。清理复用全局确认弹窗，仅删除指定轨迹及步骤；运行中的轨迹不能清理，清理后修正越界页码。

规则列表和单条编辑页共用未保存保护：站内跳转、浏览器后退与切换规则使用全局确认弹窗，刷新或关闭标签使用浏览器原生离开提示。后台规则查询刷新不会覆盖已载入的草稿。单条编辑页切换规则会清理前一条的试跑与样例状态。

规则列表顶部与各字段的「新增」统一使用非模态下拉菜单：点击外部、再次点击入口、选择项目或按 Esc 均可关闭，支持方向键和 Enter，Esc 后焦点回到入口。所有新增菜单共用展开状态，同一时间只打开一个；验证或保存期间禁用并收起。「恢复默认规则」直接显示为次要文字按钮，经确认后只替换当前草稿并清理样例结果，仍需另行保存才生效；取消不改动草稿。

保存规则前使用当前完整草稿链调用现有样例接口；样例失败或接口错误时不发送保存请求，并展示路径、规则、期望值和实际值。只有与当前规则链完全一致的成功验证结果可复用，修改后标记过期；无样例时仍执行服务端规则编译校验并明确提示未配置样例。验证和保存期间禁用重复提交，页面销毁后中止验证并忽略过期响应。脚本接口说明通过就地参考面板查看，快捷键和试跑说明保留 Tooltip；试跑默认展示提取值和命中情况，详细过程按需展开。

## 状态与请求

`EliText` 支持 `ellipsis="start"`（前省略，保留末尾）与 `ellipsis="end"`（后省略，默认）。所有专用的文件／目录路径展示统一使用前省略，涵盖工作区、批量弹窗、预览目标、整理记录、识别历史、样例、解析边界与设置授权目录；路径选择器同步使用前省略。只有实际溢出才提供完整文本 Tooltip，并在文字或尺寸变化后重新测量。文本保留完整 DOM 内容与正常阅读顺序；路径编辑框和原始 JSON／脚本日志不做省略，以免影响编辑、复制与诊断。

TanStack Query 统一管理服务端查询、去重、缓存、轮询、请求取消及写入后的失效更新。可编辑表单从查询结果复制，避免直接修改共享缓存。GET 临时失败最多重试一次，认证与参数错误不自动重试，写请求不自动重试。

登录后的布局持有整理进度与批次状态，切换页面不会停止任务观察。工作区通过服务端保存文件和作品映射；单集对照内的“查看季度”只切换 TMDB 对照视图，不修改文件、不提交保存、不清除已有整理预览。标题旁仅保留批量修正和修改作品入口。批量弹窗打开或切换来源时默认全选当前来源所有具有有效原始集号的文件，不改变工作区整理勾选；调整偏移、目标季和重新校验时保留手动取消的勾选。仅提供目标季度与一个集数偏移输入框（支持 +9、-1、0），以原始识别为基准计算偏移、不累加，支持负偏移且集号最低 E0，偏移 0 恢复原始集号；“当前映射”和“修正后”编号旁展示相对原始识别的偏移量徽章；当前映射徽章从已保存季集推导，不随弹窗草稿改变，无法表示为统一偏移时不显示；目标季度切换只在预览工具栏显示一处校验状态，并校验目标集及同集映射。关联文件和修正季集通过工作区保存接口校验。工作区和设置页离开时关闭临时弹窗。规则与调试页独立挂载，离开时取消试跑；识别历史仅加载当前分页与选中的详情。

批量修正的文件预览不分页，连续展示当前来源全部文件，沿弹窗内容区滚动；预览标题与勾选统计滚动时吸顶。仅保留表头复选框与逐行勾选，不提供快捷选择按钮。表头复选框作用于当前来源具有有效原始集号的文件；保存中、工作区忙碌或版本过期时禁止修改选择。

文件列表按季号、集号数值升序排列，支持 S0/E0，合并集按排序后的集号序列比较，同季同集按路径自然排序，未知季集排在对应层级末尾。工作区与整理预览使用当前映射，批量修正使用原始识别，避免编辑偏移导致行位置跳动；多作品预览保留作品分组，组内排序后再分页，所有排序仅影响展示，不改写保存数据。

全局 `/batches` 查询只在 `active=true` 时每 1200ms 轮询，空闲或批次完成后停止。布局挂载、窗口重新聚焦、网络重连及显式失效会刷新批次；执行成功写入批次缓存后立即恢复运行态轮询，不再使用空闲时每 5 秒的定时请求。

多作品整理预览默认使用 `duplicatePolicy=skip`，可切换 `overwrite` 并重新请求后端预览；刷新期间及策略与预览不一致时禁用确认，失败反馈使用 Toast。行 `action` 显示新增、跳过重复或无备份覆盖。跳过已有有效视频时仍登记刮削映射，整批全跳过也允许执行登记；源文件及工作区条目保留。整理只包含视频及同名字幕，NFO/图片由独立刮削工作区生成。刮削工作区按需加载每次 50 部作品、搜索并加载更多；进入作品后才检查视频可用状态，季度和单集默认折叠，整部/整季选择不受当前筛选影响。默认批量只选待办与失败；已完成项需显式重刮，单次上限 1000 个视频。预览替换作品详情而非堆叠在下方，返回选择保留当前勾选；先显示共享和逐版本产物计数，完整路径按需展开搜索；离开页面不保留未提交勾选。刮削记录单独查询和撤销。覆盖没有备份，撤销不能还原旧内容；目录、符号链接及同批次目标互撞仍阻止执行。

退出登录会取消查询、清空查询缓存和运行中任务标记，并使此前发出的响应失效。服务端工作区保留。已停用的手动工作区浏览器数据不再读写，也不会自动删除或迁移。

测试统一存放在根目录 `tests/`，执行 `make check`。
